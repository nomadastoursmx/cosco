📤 Exportar para Matriz SUCURSAL

Exporta el JSON de esta sucursal para que la Matriz lo importe y fusione los datos sin duplicados.

El archivo incluye todas las ventas, gastos, apartados, movimientos e inventario de esta sucursal con IDs únicos para evitar duplicados al fusionar.

🔀 Importar y Fusionar desde Sucursal MATRIZ

Carga el JSON exportado por una sucursal. El sistema detecta qué es nuevo, qué ya existe y te muestra los traspasos pendientes para que los apliques una sola vez.

Los datos ya importados anteriormente se ignorarán automáticamente. Los traspasos se aplican una sola vez aunque ambas sucursales los reporten.
